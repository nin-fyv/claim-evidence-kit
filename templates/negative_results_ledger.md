# Negative results ledger

Every test that did not work goes here. A failed test closes **that variant**, not the whole idea, so each entry also records what was not tested.

| Date | What was tested | Result | What was NOT tested | How the idea could still work | Pre-registration |
|---|---|---|---|---|---|
| [date] | [version, data, measure] | [fail / inconclusive, with the numbers] | [conditions, data or settings left out] | [the next variant worth trying, if any] | [link] |

## Rules
1. Add the entry the same day the result comes in.
2. Never delete an entry. If it was wrong, add a new row that corrects it.
3. Before starting a new test, read the ledger for the same idea.
